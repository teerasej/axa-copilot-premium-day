## เส้นทางการเรียนรู้วันนี้

เราจะทำงานกับ Asteria Insurance บริษัทประกันสมมติ แต่ละแบบฝึกหัดจะสร้างผลงานที่นำไปใช้ต่อในแบบฝึกหัดถัดไป

<div class="artifact-flow">

```mermaid
flowchart LR
  A["หลักฐานใน OneDrive"] --> B["Grounded Brief"]
  B --> C["KPI Insight ที่ตรวจสอบแล้ว"]
  C --> D["Decision Brief"]
  D --> E["Meeting Follow-up"]
  E --> F["Executive Update"]
```

</div>

<div class="voice-card"><strong>พล:</strong> Copilot ทำงานได้เร็ว แต่พวกเรายังเป็นคนตรวจรับงาน ลองนึกว่า Copilot คือเพื่อนร่วมงานที่เก่งและช่วยร่างได้ไว เราต้องเช็กหลักฐานก่อนส่งงานนั้นไปยังเอกสารถัดไปนะครับ</div>

## กำหนดการ

| เวลา | เส้นทางการเรียนรู้ |
|---|---|
| 09:00–10:30 | สร้าง Executive Brief จาก Copilot Chat, Work IQ และไฟล์ใน OneDrive |
| 10:30–10:45 | พัก |

| 12:00–13:00 | พักกลางวัน |
| 13:00–14:30 | เปลี่ยน Teams transcript ให้เป็น Decision และ Outlook follow-up |

| 14:45–16:00 | เปลี่ยน Evidence Pack ให้เป็น PowerPoint Executive Update ที่ผ่านการตรวจสอบ |
