# แบบฝึกหัดที่ 1 สร้าง Executive Brief ที่ตรวจสอบแหล่งข้อมูลได้

## Exercise Overview

ผู้นำของ Asteria Insurance ต้องการภาพรวมสั้น ๆ ของปัญหาการให้บริการก่อนประชุมทบทวน คุณจะเปรียบเทียบคำตอบทั่วไปจาก Copilot กับคำตอบที่อ้างอิงไฟล์ที่ได้รับอนุญาต แล้วบันทึก Evidence Brief ที่ตรวจสอบแล้วเพื่อใช้ต่อในแบบฝึกหัดถัดไป

> **License:** ต้องใช้ Microsoft 365 Copilot Premium และบัญชีผู้เรียนต้องเข้าถึง Work IQ ได้

## Prerequisites

- ลงชื่อเข้าใช้ Copilot Chat ด้วยบัญชีที่ทำงาน
- มีไฟล์ `Asteria_Operational_Context.docx` อยู่ในโฟลเดอร์ฝึกปฏิบัติบน OneDrive
- มีไฟล์ `Asteria_Service_KPI_28days.xlsx` อยู่ในโฟลเดอร์เดียวกัน
- เปิดไฟล์ทั้งสองได้

## Scenario 1 เปรียบเทียบคำตอบทั่วไปกับคำตอบที่มีหลักฐานรองรับ

ทีมผู้นำต้องการทราบว่าเกิดอะไรขึ้น เหตุใดจึงสำคัญ และต้องตัดสินใจเรื่องใด ก่อนอื่นให้สังเกตว่า Copilot รู้และไม่รู้อะไรเมื่อยังไม่ได้รับหลักฐาน

### Practice 1 สร้างคำตอบตั้งต้น

**Primary target:** ถามคำถามทางธุรกิจแบบทั่วไป แล้วระบุว่าส่วนใดของคำตอบยังเป็นเพียงข้อมูลทั่วไป ไม่ใช่ข้อเท็จจริงจาก Asteria

#### Steps

1. เปิด Copilot Chat ด้วยบัญชีที่ทำงาน
2. ปิด `Work IQ` แล้วเริ่มแชตใหม่โดยยังไม่แนบหรืออ้างอิงไฟล์ เพื่อให้คำตอบตั้งต้นใช้เฉพาะ Prompt และข้อมูลเว็บที่องค์กรอนุญาต
3. วาง Prompt นี้แล้วเลือก `Send`

   ```text
   บริษัทประกันแห่งหนึ่งใช้เวลาดำเนินการเคลมนานขึ้น มีข้อร้องเรียนจากลูกค้าเพิ่มขึ้น และมีอัตราเปลี่ยนจากผู้สนใจออนไลน์เป็นกรมธรรม์ลดลง จัดทำ Executive Brief แบบสั้น โดยระบุสาเหตุที่เป็นไปได้ ผลกระทบทางธุรกิจ และข้อเสนอแนะ 3 ข้อ
   ```

4. อ่านผลลัพธ์ แล้วทำเครื่องหมาย 3 ข้อความที่ฟังดูสมเหตุสมผล แต่ไม่มีแหล่งข้อมูลของ Asteria รองรับ
5. อย่านำคำตอบนี้ไปใส่ในเอกสารธุรกิจ

#### Checkpoint

- คุณชี้ได้อย่างน้อย 3 ข้อความที่เป็นข้อมูลทั่วไป การอนุมาน หรือยังไม่มีหลักฐานจากไฟล์ที่กำหนด
- คำตอบไม่ได้อ้างอิงไฟล์ Asteria ทั้งสองรายการ

### Practice 2 ให้ Copilot ใช้ไฟล์ที่ได้รับอนุญาต

**Primary target:** ใช้ Work IQ และระบุไฟล์อย่างชัดเจน เพื่อสร้าง Brief ที่ตรวจย้อนกลับไปยังแหล่งข้อมูลได้

#### Steps

1. เปิด `Work IQ` ใน Copilot Chat หากไม่พบตัวเลือก ให้ผู้สอนช่วยตรวจสอบบัญชี
2. เริ่มแชตใหม่
3. เพิ่มไฟล์ฝึกปฏิบัติทั้งสองไฟล์ด้วย File picker หรือพิมพ์ `/` แล้วเลือกไฟล์:
   - `Asteria_Operational_Context.docx`
   - `Asteria_Service_KPI_28days.xlsx`
   หากไฟล์ที่เพิ่ง Upload ยังไม่ปรากฏ ให้เปิดไฟล์จาก OneDrive หนึ่งครั้ง รอสักครู่ แล้วลอง File picker อีกครั้ง อย่าใช้ไฟล์งานอื่นแทน
4. วาง Prompt ด้านล่าง

   ```text
   Goal: จัดทำ Leadership Brief ที่มีหลักฐานรองรับสำหรับการทบทวนงานบริการของ Asteria

   Context: ผู้นำต้องเข้าใจว่าเกิดอะไรขึ้น เหตุใดจึงสำคัญ และต้องตัดสินใจเรื่องใด ห้ามสร้างสาเหตุ ผู้รับผิดชอบ วันที่ หรือเป้าหมายขึ้นเอง

   Sources: ใช้เฉพาะ Asteria_Operational_Context.docx และ Asteria_Service_KPI_28days.xlsx

   Expected output:
   1. ข้อเท็จจริงที่ตรวจสอบได้
   2. ข้อสมมติหรือการตีความ
   3. คำถามที่ยังไม่มีคำตอบ
   4. แหล่งข้อมูลของข้อเท็จจริงแต่ละข้อ
   5. การตัดสินใจถัดไปที่แนะนำ 1 เรื่อง

   หากแหล่งข้อมูลไม่รองรับข้อความใด ให้ระบุว่าเป็นข้อสมมติหรือตัดข้อความนั้นออก
   ```

5. ตรวจข้อเท็จจริงแต่ละข้อกับแหล่งข้อมูลที่ Copilot ระบุ และเปิดไฟล์ต้นทางเทียบเมื่อจำเป็น
6. แก้รายการที่ใช้ช่วงเวลา ตัวชี้วัด หรือแหล่งข้อมูลไม่ถูกต้อง

#### Checkpoint

- ข้อเท็จจริงทุกข้อระบุแหล่งข้อมูลหรือตำแหน่งใน Workbook
- ข้อสมมติแยกออกจากข้อเท็จจริงอย่างเห็นได้ชัด
- ข้อมูลที่ขาดถูกเขียนเป็นคำถาม ไม่ใช่คำตอบที่สร้างขึ้น

### Practice 3 บันทึกผลงานที่ตรวจสอบแล้วเพื่อส่งต่อ

**Primary target:** บันทึก Brief ที่ตรวจสอบแล้วใน Word เพื่อให้ใช้บริบทที่เชื่อถือได้ต่อในแบบฝึกหัดถัดไป

#### Steps

1. เปิดเอกสารเปล่าใน Word
2. ใส่ชื่อเรื่อง:

   ```text
   Asteria Grounded Evidence Brief
   ```

3. คัดลอกเฉพาะผลลัพธ์จาก Practice 2 ที่ตรวจสอบแล้วลงในเอกสาร
4. เพิ่มหัวข้อท้ายเอกสารว่า:

   ```text
   Human review notes
   ```

5. ใต้หัวข้อนั้น บันทึกข้อความที่คุณแก้ไข 1 ข้อ และคำถามที่ยังไม่มีคำตอบ 1 ข้อ
6. บันทึกในโฟลเดอร์ฝึกปฏิบัติบน OneDrive ด้วยชื่อ:

   ```text
   Asteria_Grounded_Evidence_Brief.docx
   ```

#### Checkpoint

- เอกสารมีข้อเท็จจริง ข้อสมมติ คำถาม แหล่งข้อมูล และบันทึกการตรวจสอบโดยมนุษย์

## Expected Output

- `Asteria_Grounded_Evidence_Brief.docx` ที่ตรวจสอบและบันทึกไว้ใน OneDrive
- เห็นความแตกต่างระหว่างคำตอบที่ไม่มีแหล่งข้อมูลกับคำตอบที่อ้างอิงหลักฐาน

<div class="voice-card"><strong>พล:</strong> การ Ground คำตอบเหมือนแนบใบเสร็จกับใบเบิกค่าใช้จ่าย แค่ข้อความดูน่าเชื่อถือยังไม่พอ ผู้ตรวจต้องเห็นด้วยว่ามีอะไรยืนยันข้อความนั้น</div>
