# ไฟล์สำหรับฝึก

ไฟล์ทั้งหมดใช้ข้อมูลสังเคราะห์ของ Asteria Insurance ซึ่งเป็นบริษัทสมมติ ไม่มีข้อมูลปฏิบัติงานหรือข้อมูลผู้เข้าอบรมของ AXA

## ดาวน์โหลดไฟล์ทั้งหมด

[ดาวน์โหลด Practice Pack ทั้งชุด](/files/Asteria_Copilot_Premium_Practice_Files.zip)

หลังดาวน์โหลด ให้แตกไฟล์ ZIP แล้ว upload ไฟล์ทั้งแปดรายการไปยัง folder `Asteria Copilot Workshop` ใน OneDrive

## เลือกดาวน์โหลดทีละไฟล์

| ไฟล์ | ใช้ในเวิร์กชอป |
|---|---|
| [Asteria_Operational_Context.docx](/files/Asteria_Operational_Context.docx) | หลักฐาน Business Context และคำถามสำหรับตัดสินใจ |
| [Asteria_Service_KPI_28days.xlsx](/files/Asteria_Service_KPI_28days.xlsx) | วิเคราะห์ KPI ตรวจ anomaly และสร้างกราฟ |
| [Asteria_Email_Thread.docx](/files/Asteria_Email_Thread.docx) | จำลอง Outlook thread แบบพกพาและเตรียมการประชุม |
| [Asteria_Meeting_Chat.docx](/files/Asteria_Meeting_Chat.docx) | จำลอง Teams chat แบบพกพาและฝึกแยกขอบเขตของ Source |
| [Asteria_Executive_Review_Transcript.vtt](/files/Asteria_Executive_Review_Transcript.vtt) | Source สำหรับให้คนตรวจ Timestamp โดยเปิดด้วยตนเอง ไม่ต้อง Attach กับ Copilot |
| [Asteria_Teams_Meeting_Recap.docx](/files/Asteria_Teams_Meeting_Recap.docx) | Meeting source แบบพกพาและตรวจแล้วสำหรับแบบฝึกสร้าง Executive Deck |
| [Asteria_Decision_Brief_Starter.docx](/files/Asteria_Decision_Brief_Starter.docx) | Starter สำหรับ Leadership Decision Brief หนึ่งหน้า |
| [Asteria_Communication_Checklist.docx](/files/Asteria_Communication_Checklist.docx) | ตรวจ Meeting, Teams และ Outlook Draft โดยมนุษย์ |
