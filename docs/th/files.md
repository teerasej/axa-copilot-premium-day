# ไฟล์สำหรับฝึก

ไฟล์ทั้งหมดใช้ข้อมูลสังเคราะห์ของ Asteria Insurance ซึ่งเป็นบริษัทสมมติ ไม่มีข้อมูลปฏิบัติงานหรือข้อมูลผู้เข้าอบรมของ AXA

## ดาวน์โหลดไฟล์ทั้งหมด

[ดาวน์โหลด Practice Pack ทั้งชุด](/files/Asteria_Copilot_Premium_Practice_Files.zip)

หลังดาวน์โหลด ให้แตกไฟล์ ZIP แล้ว upload ไฟล์ทั้งสี่รายการไปยัง folder `Asteria Copilot Workshop` ใน OneDrive
