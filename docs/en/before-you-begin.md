# Before you begin

Complete these checks before Exercise 1. The core path uses only the capabilities confirmed for this workshop.

> **License:** A Microsoft 365 Copilot Premium license and an eligible Microsoft 365 account are required. Feature visibility still depends on AXA tenant configuration and policy.

## Account and app check

Confirm that you can:

1. Sign in with your AXA work account, not a personal Microsoft account.
2. Open Copilot Chat at your organization’s approved entry point.
3. Open OneDrive, Word, Excel, PowerPoint, Outlook, and Microsoft Teams.
4. See Copilot in Word, Excel, and PowerPoint. Advanced analysis in Excel, direct Teams references in PowerPoint, Copilot in Outlook, and Copilot in Teams are optional enhancements.
5. Upload a practice file to your own OneDrive folder.
6. Open that Word file in Word for the web with permission to edit and save it.

If one required item is unavailable, tell the facilitator before continuing. Exercise 3 uses prepared files as its core path and does not require a seeded mailbox or meeting.

Start all three Exercise 3 Practices in **Microsoft 365 Copilot Chat**, using one conversation. Attach the prepared meeting recap and email thread, request the Word Action Plan, then draft the email in Chat. Word is used to review/save the Action Plan; Teams and Outlook are optional, and no email is sent. If downloadable Word generation is unavailable, the exercise provides a manual Word fallback. The communication checklist remains an optional reference, not a required output.

## Capability levels

- **Core file path:** Required learner route using standard Copilot in Excel, the prepared meeting recap, synthetic files, and portable outputs.
- **Tenant-enhanced path:** Optional use of Teams or Outlook after the facilitator confirms the app and a safe practice destination.
- **Facilitator demo:** A capability shown only after rehearsal with the intended demonstration account; participants do not need access to finish.

Each Practice ends with one or two quick checks, such as comparing a number, confirming an owner/date or opening the saved file. You do not need to fill in review-status columns or add source notes to every slide.

In Exercise 1, Chat file generation, the top Word summary panel and the predefined `Auto rewrite` command may vary by account. If file generation is unavailable, copy the brief into Word or use the prepared backup. If the top panel is absent, use Copilot's document-summary function when available. If `Auto rewrite` is unavailable, ask the facilitator or skip it; do not substitute a typed rewrite prompt. Try the separate Japanese addition afterward using Word's Copilot side panel if available.

Exercise 2's optional presentation-style comparison uses an existing PPTX as a design reference. `Reference file` availability and style matching require tenant rehearsal. A copy-and-paste/manual fallback is provided; this extension is not required to complete the dashboard or later exercises.

## Custom Agent demonstration

Session 5 uses the instructor's rehearsed Agent Builder account and synthetic files. Learners observe; they do not create agents. A recording and captured test results provide the fallback. AXA learner access to Agent Builder is not assumed. Researcher, Analyst, Copilot Studio, Cowork, Notebooks and custom skills are not required.

## UI differences

Use the current Copilot entry point in your app. If a label differs, ask the instructor to locate the equivalent function. Home, Code and Autopilot are covered briefly after Session 5; their visibility depends on rollout and they are not exercise prerequisites.

## Safe-data rules

- Use only the supplied Asteria Insurance files for the required guided exercises. Exercise 1 Practice 4 is a separate, optional private-work extension with the approval gate below.
- Do not upload real customer, health, claims, payment, security, employee, or confidential business data.
- Do not send the practice Outlook email or meeting invitation.
- Review every Copilot result before copying it into another app.
- If a source does not support a claim, label it as an assumption or remove it.
- The `.vtt` transcript is an optional reference for clarifying a meeting detail. Open it manually rather than attaching it to Copilot.

## Optional personal-work approval gate

Exercise 1 Practice 4 can use existing work context only when the facilitator/client approves the activity and its data scope. Permission to access information does not by itself authorize classroom use.

- Use your own work account and a fresh private chat, separate from Asteria. Keep screen sharing off.
- Use only approved, suitable information; do not upload real work data for the exercise. Stop if unrelated or unsuitable sensitive content appears.
- Keep real work results out of Asteria documents, sample folders, shared screens, workshop submissions, and the public repository.
- Confirm the meeting and date/time in your calendar. Do not send messages, invite anyone, or change calendar entries.
- Skip the extension if approval, access, or data suitability is uncertain. Every required exercise can be completed with the prepared files.

## Prepare your folder

1. [Open the practice-files page](./files) and download the ZIP or individual files.
2. In OneDrive, create a folder named:

   ```text
   Asteria Copilot Workshop
   ```

3. Extract the eleven-file ZIP: eight sources, two backups and one presentation template. Upload the eight source files into that folder, but keep `Asteria_Grounded_Evidence_Brief.docx`, `Asteria_Service_KPI_Reviewed_backup.xlsx` and `Asteria_Presentation_Template.pptx` separate until needed. These prepared assets must not replace outputs you create yourself.
4. Keep the filenames unchanged so later prompts can find them.

If Exercise 1 cannot produce a usable Word brief, [download the prepared backup brief](/files/Asteria_Grounded_Evidence_Brief.docx) or use the ZIP copy. Open it, spot-check two facts and the reporting period, then continue.

If the Excel practices cannot produce a usable workbook, [download the reviewed KPI backup](/files/Asteria_Service_KPI_Reviewed_backup.xlsx) or use the ZIP copy. Open its findings and chart, compare one number with `KPI_Data`, then continue to PowerPoint. Its additional review fields are optional. Ask the facilitator about account or OneDrive access problems.

For the optional style comparison, [download the Asteria presentation template](/files/Asteria_Presentation_Template.pptx) or keep the ZIP copy available. Upload it to OneDrive when the optional practice asks for it; it is a design reference, not a new source of business evidence.
