# Before you begin

Complete these checks before Exercise 1. The core path uses only the capabilities confirmed for this workshop.

> **License:** A Microsoft 365 Copilot Premium license and an eligible Microsoft 365 account are required. Feature visibility still depends on AXA tenant configuration and policy.

## Prepare your files

One download includes **all eleven files**: eight sample source files, two prepared backup work files and one presentation template. The ZIP already places the backups and template in a separate subfolder; you do not need to sort the files yourself.

1. [Download the complete practice ZIP](/files/Asteria_Copilot_Premium_Practice_Files.zip) to your computer.
2. Extract the ZIP. On Windows, right-click it and choose **Extract All**. On a Mac, double-click it. Inside the extracted contents, locate this folder:

   ```text
   Asteria Copilot Workshop
   ```

   It contains eight source files and a `Prepared assets` subfolder holding the two backups and presentation template.
3. Open **OneDrive** in Microsoft Edge or Google Chrome and sign in with your work account. In your own files, select **Add new > Folder upload** (or **Upload > Folder** if that is the menu shown).
4. Select the extracted `Asteria Copilot Workshop` folder and upload the **whole folder**, including `Prepared assets`. Do not upload the ZIP itself or the extra extraction wrapper folder. Keep the filenames unchanged.
5. Wait for the upload to finish. Open the folder in OneDrive and confirm that the eight source files and the `Prepared assets` subfolder are present. Open that subfolder and check these three files:

   - `Asteria_Grounded_Evidence_Brief.docx`
   - `Asteria_Service_KPI_Reviewed_backup.xlsx`
   - `Asteria_Presentation_Template.pptx`

6. Return to the main workshop folder and open `Asteria_Operational_Context.docx` in **Word for the web**. Confirm that you can open it with permission to edit and save.

Save your own exercise outputs in the main workshop folder. Leave the prepared copies in `Prepared assets`, retain their filenames and prepared labels, and do not overwrite them with your own work.

**If folder upload is unavailable:** try Microsoft Edge or Google Chrome. If your organization still blocks uploading, ask the facilitator before continuing. If only folder upload is unavailable but file upload works, create the same two folders in your own OneDrive and upload the eight sources and three prepared assets to their matching locations.

For help with the upload controls, see [Microsoft's OneDrive upload guidance](https://support.microsoft.com/en-us/onedrive/upload-and-save-files-and-folders-to-onedrive).

## Capability levels

- **Core file path:** Required learner route using standard Copilot in Excel, the prepared meeting recap, synthetic files, and portable outputs.
- **Tenant-enhanced path:** Optional use of Teams or Outlook after the facilitator confirms the app and a safe practice destination.

## Safe-data rules

- Use only the supplied Asteria Insurance files for the required guided exercises. Exercise 1 Practice 4 and Exercise 3 Scenario 3 are separate, optional private-work extensions with the approval gate below.
- Do not upload real customer, health, claims, payment, security, employee, or confidential business data.
- Do not send the practice Outlook email or meeting invitation.
- Review every Copilot result before copying it into another app.
- If a source does not support a claim, label it as an assumption or remove it.
- The `.vtt` transcript is an optional reference for clarifying a meeting detail. Open it manually rather than attaching it to Copilot.

## Optional personal-work approval gate

Exercise 1 Practice 4 and Exercise 3 Scenario 3 can use existing work context only when the facilitator/client approves the activity and its data scope. The same gate applies to Exercise 3's optional Outlook source. Permission to access information does not by itself authorize classroom use.

- Use your own work account and a fresh private chat, separate from Asteria. Keep screen sharing off.
- Use only approved, suitable information; do not upload real work data for the exercise. Stop if unrelated or unsuitable sensitive content appears.
- Keep real work results out of Asteria documents, sample folders, shared screens, workshop submissions, and the public repository.
- Confirm the meeting and date/time in your calendar. Do not send messages, invite anyone, or change calendar entries.
- For Exercise 3 Scenario 3, confirm the selected past meeting's recording and retained transcript are accessible. Do not treat meeting attendance or a Copilot search result as proof of transcript access.
- Skip the extension if approval, access, or data suitability is uncertain. Every required exercise can be completed with the prepared files.
