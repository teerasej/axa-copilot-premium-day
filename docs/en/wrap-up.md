## Choose your role lens

| Role lens | Question to take back to work |
|---|---|
| Operations | Which recurring review can use a standard evidence and action format? |
| Distribution | Which channel update needs faster comparison without losing source detail? |
| Technical | Which model or portfolio explanation would benefit from a verified brief? |
| Finance | Which decision pack can separate calculated evidence from management assumptions? |
| IT | Which service review needs clearer ownership, dependencies, and technical limits? |
| Risk | Which risk discussion needs stronger links between evidence, exposure, and next action? |
| Legal and Compliance | Which draft should include a mandatory source and human-approval check? |
| Security | Which review can use synthetic inputs before any restricted data is considered? |
| Marketing | Which campaign review can move from performance data to an approved communication pack? |
| Executive office | Which leadership meeting can use one evidence-to-decision handoff across apps? |
