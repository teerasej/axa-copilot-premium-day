# Session 5 Custom Agent demonstration

## Session Overview

Observe a prepared Custom Agent that helps review meeting evidence and draft an Action Plan. You do not create an agent in this workshop.

## Prerequisites

No learner agent access is required. The instructor uses a rehearsed Agent Builder account in the instructor's tenant with synthetic files. AXA learner access is not assumed.

## Demonstration

Observe the prepared `Meeting Action Plan Coach`:

1. Its purpose, instructions and approved knowledge.
2. A supported request grounded in meeting evidence.
3. A request with a missing owner or date.
4. An out-of-scope request.

Check whether it cites sources, preserves missing information and distinguishes proposals from decisions. If the live demonstration is unavailable, the instructor uses a recording and captured test results.

## Observation check

- Identify one source-supported answer.
- Identify one missing detail the agent should not invent.
- Explain which result needs human review.

## Expected Output

One note describing a possible workplace application and its required source and review. No learner agent creation, publication or sharing is required.
